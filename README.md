A responsive, static portfolio for [abcxyzwithoutu.github.io](https://abcxyzwithoutu.github.io/).

## Preview locally

Serve this directory with a static server, for example `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Publish on GitHub Pages

Push the `main` branch to `abcxyzwithoutu/abcxyzwithoutu.github.io`. In repository **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`. No build step is required.
